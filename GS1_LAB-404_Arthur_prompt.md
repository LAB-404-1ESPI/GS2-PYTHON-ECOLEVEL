Durante o desenvolvimento do projeto EcoLevel, utilizamos a Inteligência Artificial como ferramenta de apoio para solucionar dúvidas pontuais, melhorar a organização do código e auxiliar na documentação do projeto.

A IA foi utilizada principalmente para:

1. Organização do código
- Como dividir o programa em funções menores para facilitar a leitura e manutenção?
- Como organizar melhor os menus e as funcionalidades do sistema?
2. Validação de dados
- Como impedir que o usuário realize um cadastro com campos vazios?
- Como verificar se um e-mail já está cadastrado?
- Como validar entradas numéricas e impedir valores negativos no registro de peso?
3. Sistema de pontuação
- Como calcular automaticamente XP e moedas de acordo com o peso de material reciclável aprovado?
- Como impedir que uma mesma entrega gere pontos mais de uma vez?
- Como implementar níveis e recompensas conforme a evolução do usuário?
4. Armazenamento de informações
- Como utilizar arquivos JSON para salvar os usuários, descartes e pontuações?
- Como recuperar os dados salvos quando o programa for executado novamente?
5. Tratamento de erros
- Como utilizar try/except para evitar que entradas inválidas interrompam a execução do programa?
- Como tratar possíveis erros durante a leitura e gravação dos arquivos?
6. Documentação
- Como estruturar o README.md com a apresentação, funcionalidades e instruções de execução do projeto?
- Como descrever os requisitos utilizados e explicar o funcionamento do sistema?
- Como organizar a documentação para facilitar a compreensão dos professores e avaliadores?
Participação da equipe
As sugestões fornecidas pela IA foram utilizadas como auxílio durante o desenvolvimento. A equipe ficou responsável por analisar, adaptar e revisar as soluções de acordo com os requisitos da atividade e as necessidades do EcoLevel.

A utilização da ferramenta também contribuiu para esclarecer dúvidas sobre Python, melhorar a organização do projeto e facilitar a elaboração de sua documentação.
